# 경동대학교 셔틀버스 예약 시스템

> 소프트웨어개발 1회차 프로젝트 · 2026.09 · 개인 개발 (경동대학교 소프트웨어학과 이유빈)

메트로폴(양주)·메디컬(원주문막) 캠퍼스 셔틀버스 좌석을 학번으로 예약하고,
관리자가 배차·지연·노쇼를 관리하는 Flask 웹 서비스입니다.

## 주요 기능

| 구분 | 기능 |
|---|---|
| 학생 | 학번으로 접속, 캠퍼스·노선·방향·시간대별 좌석 선택 예약, 예약 취소, 만석이면 대기열 등록(선착순 자동 승격), 즐겨찾기 노선, 나의 예약 기록 |
| 관리자 | 배차 시간표 추가·삭제(관련 예약·대기 함께 정리), 실시간 지연 시간 반영, 탑승객 명단, 노쇼 처리(3회 누적 시 7일 예약 정지) |
| 자동 처리 | 출발한 버스의 예약·대기 자동 정리, 예약 정지 기한이 지나면 자동 복구, 모든 예약·취소·노쇼 이력 기록 |
| 데이터 무결성 | 한 학생 한 좌석, 같은 좌석 중복 예약 방지 (DB UNIQUE 제약) |

## 기술 스택

Python · Flask · SQLite · Jinja2 · HTML/CSS/JavaScript

## 실행 방법

```
python -m pip install flask
python app.py
```

브라우저에서 http://localhost:5000 에 접속합니다. 데이터베이스(`shuttle.db`)는 처음 실행할 때 자동으로 만들어집니다.
데이터베이스 관련 오류가 나면 `python reset_db.py`로 초기화한 뒤 다시 실행합니다.
